# llm-movie-recommendation-system.ipynb
This project is a movie and TV show recommendation system based on user watch history using an LLM-based approach.
## Project Note

This project was developed as a course project.
Turkish language expressions are used in the project content and code.

## Features

* User-based movie recommendation
* Data preprocessing and cleaning
* LLM-ready dataset structure
* Simple and modular design

## Technologies Used

* Python
* Pandas
* Jupyter Notebook

## Project Structure

* llm-movie-recommendation-system.ipynb : Main notebook file
* Dataset files (if included)

## Usage

1. Open the notebook file
2. Run all cells step by step
3. Review the generated recommendations

## About the Project

The system processes user watch history and movie metadata such as overview, genres, and ratings to generate personalized recommendations.
